# Свидетельства checkpoint 9 ноября 2026

Небольшие побайтовые копии оригинальных JSON/журнала. SHA256 и исходные локальные пути указаны в manifest.json. Каталог versioned: для чтения этих результатов не требуется наличие игнорируемого results/. Полные сырые измерения, NPZ/HAR/HEF, ключи и исходники vendor остаются вне Git; здесь только отчёты, сводки и provenance.

pi/ — оригинальные файлы, выполненные пользователем на Raspberry Pi и перенесённые им на ПК через SCP. smoke-001 сохраняет ошибку DMA; smoke-002 и qualification-001 — успешное реальное выполнение. Значение hardware_qualification=true в qualification-001 относится к явно записанному qualification_scope: NPU, независимая INT64-свёртка, оба SparseNTRU kernels и восстановление сессии. Torch/SymPy/liboqs на Pi этим не подтверждены.

pc/ — исторические аппаратные отчёты N17/N107/N701, парные эксперименты host/Sparse, отдельные сводки OQS arithmetic и KEM, квалификация и сборочное происхождение liboqs, ASan/UBSan и ограниченный runtime на x86. Исторические счётчики software_tests в отчётах не заменяют финальный прогон checkpoint. Пулы и отдельные запуски не смешивать между экспериментами.

Стандартные версии/пути в manifest сборок liboqs относятся к исходной машине; это свидетельства сборки, не переносимые ARM-бинарники и не инструкции менять профиль текущего runtime.
